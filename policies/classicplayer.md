# クラシック名曲プレイヤー プライバシーポリシー

制定日：2026年11月20日 ／ 改定日：2026年11月21日（音源の通信先に制作者の旧サーバーを追加。オフライン再生のためのダウンロードを追加）

Kaito Kitaya（以下「運営者」）は、スマートフォン向けアプリ「クラシック名曲プレイヤー」（英語名 Classical Masterpieces Player。以下「本アプリ」）での情報の取り扱いについて、以下のとおり定めます。

## 1. 基本方針

本アプリは、利用者の個人情報や利用状況のデータを収集しません。アカウント登録はなく、広告・アクセス解析・クラッシュ収集の仕組みも組み込んでいません。

## 2. 端末の中だけに保存する情報

次の情報は、機能を提供するためにお使いの端末の中だけに保存します。運営者やほかの第三者に送信することはありません。本アプリを削除すると消えます。

- お気に入りに登録した曲と、登録した日時
- 最近再生した曲（最大100件）
- 最近の検索語（最大10件）
- 再生キューと再生位置
- オフラインで聴くためにダウンロードした音源ファイルと、ダウンロードの設定（Wi-Fi のときだけ取得するか）
- 曲目カタログと作曲家の肖像画（第3項の 3-1 で取得したもの）
- 「応援者」バッジの表示の有無（チップを購入した場合）

## 3. 本アプリが行う通信

本アプリが通信するのは、次の 2 つだけです。どちらも、利用者を識別する情報を本アプリから付け加えて送ることはありません。

### 3-1. 曲目カタログの取得

GitHub Pages（kate941-su.github.io）から、曲目の一覧（JSON ファイル）と、作曲家の肖像画（Wikimedia Commons の画像を運営者が加工して置いたもの）を取得します。本アプリが Wikimedia に直接アクセスすることはありません。

### 3-2. 音源の再生とダウンロード

曲を再生するとき、[CMSL クラシック名曲サウンドライブラリー](https://classical-sound.seesaa.net/)の音源ファイル（classical-sound.up.seesaa.net）を直接ストリーミングします。曲をダウンロードするときも、同じ音源ファイルを同じ通信先から取得します。

2011〜2012 年ごろに公開された一部の曲は、音源の制作者の旧サーバー（classical-music.aki.gs、andotowa.sakura.ne.jp、classical-music.sakura.ne.jp）から再生します。これらのサーバーは暗号化通信（https）に対応していないため、この通信は暗号化されず、同じネットワーク上の第三者に再生中の曲が分かる可能性があります。

### 3-3. 通信先が受け取る情報

通信の際、通信先のサーバーには、一般的なインターネット通信と同様に IP アドレスなどが届きます。これらは各サービスの方針に従って扱われます。運営者がこれらの情報を受け取ることはありません。

- GitHub のプライバシーステートメント：https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement
- Seesaa：https://www.seesaa.co.jp/
- 旧サーバー：各ホスティング事業者の方針に従います

## 4. アプリ内課金（チップ）

任意のチップ（寄付）の購入は、App Store または Google Play の決済の仕組みで行われ、Apple または Google が処理します。運営者は、氏名・連絡先・決済情報などの個人情報を受け取りません。チップを購入しても、機能や曲が増えることはありません。

## 5. 広告とトラッキング

本アプリは広告を表示せず、他社のアプリやウェブサイトをまたいだトラッキングを行いません。

## 6. お子さまの利用

本アプリは個人情報を収集しないため、お子さまが利用する場合も、個人情報が送信されることはありません。

## 7. 本ポリシーの変更

本アプリの通信や保存する情報を変える場合は、このページを更新し、改定日を記載します。

## 8. お問い合わせ

本ポリシーについてのお問い合わせは、[GitHub Issues](https://github.com/Kate941-su/classicplayer/issues) にお寄せください（公開の場所なので、個人情報は書かないでください）。
