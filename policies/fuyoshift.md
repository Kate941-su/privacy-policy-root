# 扶養バイト管理 プライバシーポリシー

制定日：2026年11月26日

Kaito Kitaya（以下「運営者」）は、スマートフォン向けアプリ「扶養バイト管理」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

## 1. 基本方針

- 本アプリは**会員登録が不要**で、氏名・メールアドレス・電話番号などをお聞きしません。
- 本アプリに入力した**シフト、時給、収入、生年月日などは、利用者の端末の中にだけ保存**され、運営者のサーバーや第三者に送信されることはありません。運営者はこれらのデータを受け取らず、閲覧もできません。
- 本アプリ自体には、アクセス解析やクラッシュ収集のためのツールは入っていません。

## 2. 端末の中にだけ保存する情報

次の情報は端末内に保存され、外部には送信されません。

| 情報 | 内容 |
|---|---|
| プロフィール | 扶養の状況（親の扶養・配偶者の扶養など）、生年月日、学生かどうかなど、壁の判定に使う項目 |
| 勤務先 | 名前、時給・日給、交通費、締め日・給料日、割増のルール、従業員数の区分など |
| シフト | 日時、休憩、メモ、シフトパターン |
| 給料明細 | 利用者が入力した実際の支給額 |
| 予定・メモ | カレンダーに記録した私用の予定やメモ |
| 設定 | 通知の設定、送った通知の記録、有料版の購入状態など |

- **通知**は、端末の中で予約する通知（ローカル通知）だけです。サーバーからの送信はありません。
- **バックアップ（書き出し）**は、利用者が操作したときにだけファイルを作成し、利用者が選んだ保存先（iCloud Drive、Google ドライブなど）に渡します。保存先での取り扱いは、各サービスの規約に従います。
- Android の OS の自動バックアップは使っていません。
- 本アプリを削除すると、これらの情報は端末から削除されます。

## 3. 通信する場面と第三者が取得する情報

本アプリが通信するのは、次の場面だけです。いずれの場面でも、上記 2 の情報（シフト、時給、収入、生年月日など）は送りません。

### 3-1. 壁と祝日の情報の取得

制度の改正に合わせて、扶養の壁の金額と祝日の情報を、運営者が用意した配信用のサーバーから取得することがあります。この通信では、ファイルを受け取るだけで、利用者の情報は送りません。通信の際、一般的なウェブの通信と同じく、IP アドレスなどがサーバーの事業者の記録に残ることがあります。

### 3-2. 広告（Google AdMob）

本アプリの無料版では、Google LLC が提供する広告サービス「Google AdMob」を利用しています。広告の配信のため、Google は端末から次のような情報を取得することがあります。

- IP アドレス、端末やアプリの情報（OS、アプリのバージョンなど）
- 広告の表示・タップなどの操作の情報
- 不具合の調査のための診断情報

18歳未満の方も利用されるため、本アプリは次のように設定しています。

- **利用者の興味・関心に基づく広告（パーソナライズ広告）は、すべての利用者に配信しない**設定で広告をリクエストしています。
- Android では広告 ID を利用する権限を外しています。iOS では、他社のアプリやウェブサイトをまたいだトラッキングの許可（ATT）を求めません。
- 広告に年齢や生年月日を渡しません。広告の内容は、10代の方にも適した区分に限っています。

**有料版では広告を表示しません。**

Google による情報の取り扱いは、次をご確認ください。

- Google のプライバシーポリシー：https://policies.google.com/privacy
- Google のパートナーのサイトやアプリでのデータの使用：https://policies.google.com/technologies/partner-sites

### 3-3. 有料版の購入（Apple・Google・RevenueCat）

有料版の購入は、Apple（App Store）または Google（Google Play）の決済の仕組みで行われます。お支払いの情報（クレジットカード番号など）は Apple・Google が管理し、運営者が受け取ることはありません。

購入状態の確認には、RevenueCat, Inc. のサービス「RevenueCat」を利用しています。RevenueCat は、購入の確認のため、アプリごとに発行される匿名の利用者 ID、購入の履歴（商品、購入日、有効期限など）、端末やアプリの情報を取得します。運営者は、RevenueCat の管理画面で、これらの購入の情報を確認できます。氏名やメールアドレスは含まれません。

- RevenueCat のプライバシーポリシー：https://www.revenuecat.com/privacy

## 4. 情報の第三者への提供

運営者は、上記 2 の情報を保有していないため、第三者に提供することはありません。第 3 項の第三者による取得は、各社の規約・ポリシーに基づいて行われます。

## 5. 対象年齢

本アプリは年齢を問わず利用できます。18歳未満の方が有料版を購入する場合は、保護者の方の同意を得てください。

## 6. 利用者の権利

運営者は利用者の入力したデータを保有していないため、データの開示・訂正・削除のご依頼には、本アプリ内の機能（各項目の編集・削除、アプリの削除）でご対応ください。広告に関する情報は、上記の Google のページや端末の設定から管理できます。購入の情報の削除をご希望の場合は、お問い合わせ先までご連絡ください。

## 7. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本アプリ内またはウェブサイトでお知らせします。
