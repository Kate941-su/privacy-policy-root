# ドパ脱！ プライバシーポリシー

制定日：2026年10月30日

Kaito Kitaya（以下「運営者」）は、スマートフォン向けアプリ「ドパ脱！」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

## 1. 基本方針

- 本アプリは**アカウント登録が不要**で、氏名・メールアドレス・電話番号などをお聞きしません。
- 本アプリで記録したデータは**利用者の端末の中にだけ保存**され、運営者のサーバーに送信されることはありません。運営者はこれらのデータを受け取らず、閲覧もできません。
- 本アプリ自体には、アクセス解析やクラッシュ収集のためのツールは入っていません。

## 2. 端末の中にだけ保存する情報

次の情報は端末内に保存され、外部には送信されません。

| 情報 | 内容 |
|---|---|
| 記録 | 習慣を断った期間（開始・終了の日時）、到達した段位 |
| 衝動のログ | 日時、強さ、気分、場所、きっかけ、実行した代わりの行動、メモ |
| 設定 | やめたい習慣、理由、目標日数、通知の時刻、見た目の設定など |
| アプリロックの PIN | 元の数字は保存せず、ソルト付きのハッシュ値を端末の安全な保管領域（iOS のキーチェーン／Android の Keystore を使う領域）に保存します |

- **生体認証（Face ID・指紋など）**は OS の機能を利用しており、本アプリが顔や指紋の情報を取得・保存することはありません。
- **通知**は端末の中で予定する通知（ローカル通知）だけで、サーバーからの送信はありません。通知の文面には、習慣の内容がわかる言葉は含めません。
- **バックアップ（エクスポート）**は、利用者が操作したときにだけファイルを作成し、利用者が選んだ方法（共有先）で保存・送信されます。PIN と購入状態は含みません。
- 本アプリを削除するか、設定の「全データ削除」を行うと、これらの情報は端末から削除されます。

## 3. 第三者が取得する情報

### 3-1. 広告（Google AdMob）

本アプリの無料版では、Google LLC が提供する広告サービス「Google AdMob」を利用しています。広告の配信のため、Google は端末から次のような情報を取得することがあります。

- 広告識別子などの端末の識別子、IP アドレス、端末やアプリの情報（OS、アプリのバージョンなど）
- 広告の表示・タップなどの操作の情報、おおよその位置情報（IP アドレスから推定されるもの）
- 不具合の調査のための診断情報

本アプリは、**利用者の興味・関心に基づく広告（パーソナライズ広告）を配信しない設定**で広告をリクエストしています。iOS では、他社のアプリやウェブサイトをまたいだトラッキングの許可（ATT）を求めません。また、性的な内容・出会い系・ギャンブル・アルコールなどの広告を表示しないよう設定しています。

欧州経済領域（EEA）・英国などでは、法令に基づき、広告に関する同意をお聞きする画面を表示します。同意の内容は、設定の「広告の同意設定」からいつでも変更できます。

**プレミアム（有料）を購入した場合、広告の機能は読み込まれず、Google AdMob による情報の取得は行われません。**

Google による情報の取り扱いは、次をご確認ください。

- Google のプライバシーポリシー：https://policies.google.com/privacy
- Google のパートナーのサイトやアプリでのデータの使用：https://policies.google.com/technologies/partner-sites

### 3-2. アプリ内課金（Apple・Google）

プレミアムの購入は、Apple（App Store）または Google（Google Play）の決済の仕組みで行われます。お支払いの情報（クレジットカード番号など）は Apple・Google が管理し、運営者が受け取ることはありません。本アプリは、購入が済んでいるかどうかの情報だけをストアから受け取り、端末に保存します。

## 4. 情報の第三者への提供

運営者は、利用者の情報を保有していないため、第三者に提供することはありません。第 3 項の第三者による取得は、各社の規約・ポリシーに基づいて行われます。

## 5. 対象年齢

本アプリは 18 歳以上の方を対象としています。

## 6. 利用者の権利

運営者は利用者の記録を保有していないため、記録の開示・訂正・削除のご依頼には、本アプリ内の機能（記録の編集、全データ削除、アプリの削除）でご対応ください。広告に関する情報については、上記の Google のページや、端末の設定（広告 ID のリセット・削除など）から管理できます。

欧州経済領域（EEA）・英国にお住まいの方の広告に関する情報の取り扱いは、同意に基づきます。同意はいつでも撤回できます。

## 7. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本アプリ内またはウェブサイトでお知らせします。
