# Data Holder プライバシーポリシー

Data Holder（以下「本アプリ」）は、利用者のプライバシーを尊重し、次のとおり情報を取り扱います。

### 1. 端末内での保存
本アプリに入力・保存した情報（Vault の名前・項目名・値、フォルダ名、タグ、パスポートから読み取った情報、顔写真など）は、利用者の端末の中にだけ保存されます。項目名と値（顔写真を含みます）は、端末内で生成した鍵で暗号化して保存し、その鍵は端末のセキュアな領域（Android Keystore / iOS キーチェーン）で保護されます。Vault の名前、フォルダ名、タグは暗号化せずに端末内に保存します。開発者を含む第三者に、これらの情報が送信されることはありません。アプリをアンインストールすると、端末内のデータは削除されます。

### 2. 通信
本アプリは、次項のクラウドバックアップを除き、インターネットとの通信を行いません。広告、アクセス解析、クラッシュレポートなどの外部サービスも使用していません。

### 3. クラウドバックアップ（任意・Pro 機能）
本節は、クラウドバックアップ機能を提供するバージョン以降に適用されます。この機能は、利用者が有効にした場合にのみ動作します。

- バックアップは、利用者が設定したバックアップパスワードを使って端末内で暗号化（AES-256）してから、利用者本人の Google ドライブのアプリ専用領域（appDataFolder）に保存します。
- バックアップパスワードと暗号化の鍵は、開発者にも Google にも送信されません。開発者も Google も、バックアップの中身を読むことはできません。
- 開発者はサーバーを運用しておらず、バックアップを受信・保存・閲覧しません。
- 本アプリが Google アカウントで利用する権限は、本アプリ専用領域のファイルの作成・読み取り・削除（`drive.appdata`）のみです。Google ドライブ内のその他のファイルにはアクセスしません。
- 本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use の要件を含む [Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy) に準拠します。
- 機能を無効にする際は、アプリからクラウド上のバックアップを削除できます。Google アカウントの設定から本アプリのアクセス権を取り消すこともできます。
- バックアップパスワードを忘れた場合、バックアップを復元することはできません。

### 4. パスポートの読み取り（NFC）
パスポートの IC チップを読み取るために、利用者が入力した旅券番号・生年月日・有効期限を使用します。これらはチップを開くためだけに使い、保存しません。チップから読み取った情報（氏名、国籍、生年月日、旅券番号、顔写真など）は、利用者が保存を選んだ場合にのみ、第 1 項のとおり端末内に暗号化して保存します。チップの真正性の確認は、アプリに同梱した証明書を使って端末内で行い、通信は行いません。

### 5. 手動バックアップファイル
設定画面から書き出すバックアップファイルは、利用者が設定したパスワードで暗号化されます。ファイルの保存先や送信先は利用者が選び、開発者がこのファイルを受け取ることはありません。

### 6. クリップボード
値をコピーすると、端末のクリップボードに保存されます。クリップボードの内容は、端末の他のアプリから参照できる場合があります。コピーした値は、60 秒後にクリップボードから自動で消去します（その間に別の内容をコピーした場合を除きます）。Android 13 以降では、コピー時に表示されるプレビューで値を伏せて表示します。なお、OS の制約により、本アプリが動作していない間は消去されない場合があります。

### 7. アプリ内購入
Pro の購入は、Google Play または App Store を通じて処理されます。開発者が支払い情報を受け取ることはありません。

### 8. 子どものプライバシー
本アプリは 13 歳未満の子どもを対象としていません。
