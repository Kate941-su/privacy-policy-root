# Data Holder 利用規約

制定日：2026年11月2日

この利用規約（以下「本規約」）は、Kaito Kitaya（以下「運営者」）が提供するスマートフォン向けアプリ「Data Holder」（以下「本アプリ」）の利用条件を定めるものです。本アプリをダウンロードまたは利用した時点で、本規約に同意したものとみなします。

## 第1条（本アプリの内容）

1. 本アプリは、ログイン情報、身分証明書の記載事項、メモなどの情報を、利用者の端末内に暗号化して保管するためのツールです。
2. 本アプリは、NFC に対応した端末で、パスポートの IC チップに記録された情報を読み取り、保管する機能を提供します。
3. 本アプリによるチップの真正性の確認結果は、参考情報です。本アプリは、公的な本人確認や身分証明書の真贋判定に用いることを目的としたものではありません。

## 第2条（利用条件）

1. 本アプリは、13歳以上の方を対象としています。
2. 本アプリはアカウント登録なしで利用できます。
3. パスポートなどの身分証明書は、利用者本人のもの、または所持者本人の同意を得たものに限って読み取ってください。

## 第3条（データの保存とバックアップ）

1. 本アプリで保存したデータは、利用者の端末の中に暗号化して保存され、運営者のサーバーには送信されません。
2. 端末の故障・紛失・初期化、本アプリの削除などにより、データは失われることがあります。本アプリのバックアップ機能で、定期的にバックアップを取ってください。
3. バックアップはパスワードで暗号化されます。パスワードを忘れた場合、運営者を含め誰もバックアップを復元できません。
4. 運営者は利用者のデータを保有していないため、失われたデータを復元することはできません。

## 第4条（有料機能）

1. 本アプリの一部の機能（以下「Pro」）は、アプリ内課金（買い切り）で利用できます。価格は購入時にストアに表示される金額とします。
2. 無料で保存できる Vault の数には上限があります。上限を超えて保存済みのデータは、Pro を購入しなくても閲覧・編集できます。
3. 購入・支払い・返金は、Apple（App Store）または Google（Google Play）の規約と手続きに従います。運営者は、購入代金の返金を直接は行いません。
4. 機種変更などの際は、同じ Apple ID / Google アカウントで本アプリの「購入を復元」を行うと、Pro を再度利用できます。
5. Pro の内容は、改善のために変更されることがあります。ただし、購入済みの利用者が受けられる主な機能を、合理的な理由なく取り除くことはしません。

## 第5条（禁止事項）

利用者は、次の行為をしてはなりません。

1. 法令または公序良俗に反する行為
2. 他人の身分証明書を、所持者本人の同意なく読み取る行為
3. 本アプリのリバースエンジニアリング、改変、複製、再配布（法令で認められる場合を除く）
4. 不正な方法で有料機能を利用する行為
5. 本アプリまたは第三者のサービスの運営を妨げる行為

本アプリに含まれるプログラム、イラスト、文章、デザインなどの権利は、運営者または正当な権利者に帰属します。本規約は、本アプリを個人で利用する範囲を超えて、これらの権利を利用者に許諾するものではありません。

1. 運営者は、本アプリに不具合がないこと、特定の目的に適合すること、すべての端末・身分証明書で読み取りができることを保証しません。
2. 運営者は、本アプリの利用または利用できないことによって利用者に生じた損害（データの消失を含みます）について、運営者の故意または重大な過失による場合を除き、責任を負いません。
3. 前項にかかわらず、運営者が責任を負う場合でも、その範囲は、利用者が本アプリに支払った金額を上限とします（運営者の故意または重大な過失による場合を除きます）。
